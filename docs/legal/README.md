# 약관 · 개인정보처리방침

## 원문이 어디 있나

**마크다운이 아니라 코드에 있다.**

```
apps/web/src/domains/legal/
├─ operator.ts            운영자 이름·연락처 등 두 문서가 함께 쓰는 값
├─ terms.ts               이용약관
├─ privacy.ts             개인정보처리방침
├─ legalTypes.ts          문서의 뼈대
└─ LegalDocumentView.tsx  화면에 그리는 곳
```

여기를 고치면 웹의 `/terms`, `/privacy` 가 함께 바뀐다.
앱은 이 주소를 브라우저로 열 뿐이라 따로 고칠 것이 없다.

문서를 마크다운으로도 두지 않은 이유는 하나다. **두 벌이 되면 반드시 한쪽만 고쳐진다.**
실제와 다른 고지는 고지를 하지 않은 것보다 나쁘다.

## 공개 전에 반드시 채울 것

`operator.ts` 의 대괄호 값이 그대로 남아 있으면 **방침을 게시하지 않은 것과 같다.**
보호책임자와 연락처는 개인정보보호법 제30조가 정한 의무 기재사항이다.

| 값 | 무엇 |
| --- | --- |
| `name` | 운영자(개인 이름 또는 상호) |
| `contactEmail` | 문의·열람청구·삭제요청을 받을 주소 |
| `privacyOfficer` | 개인정보 보호책임자. 1인 운영이면 운영자와 같은 사람 |
| `hostingProvider` | 서버를 빌려 쓰는 사업자. 배포처를 정한 뒤 |
| `effectiveFrom` | 시행일. 서비스를 여는 날로 |

## 어디에 링크해야 하나

| 곳 | 필요한 주소 |
| --- | --- |
| 카카오 개발자센터 앱 설정 | `/privacy` |
| 구글 OAuth 동의 화면 (운영 모드 전환 시) | `/privacy`, `/terms` |
| App Store Connect — 앱 개인정보 | `/privacy` |
| Google Play Console — 데이터 안전 | `/privacy` |
| Google Play Console — **계정 삭제 요청 URL** | `/account/delete` |

`/account/delete` 가 따로 있는 이유는 구글 플레이의 데이터 삭제 정책 때문이다.
**앱을 이미 지운 사람**도 삭제를 요청할 수 있어야 해서, 앱 밖에서 닿는 주소를 요구한다.

## 회원탈퇴가 실제로 하는 일

| 시점 | 무슨 일 |
| --- | --- |
| 탈퇴 즉시 | `users.deleted_at` 기록, 리프레시 토큰 전량 폐기 |
| 탈퇴 즉시 | 남은 액세스 토큰으로도 API 가 401 을 준다 (`CurrentUserService`) |
| 30일 안에 재로그인 | `deleted_at` 을 지우고 계정·기록을 그대로 복구 |
| 30일 경과 | 매일 새벽 4시 배치가 계정과 자식 행을 전부 삭제 (`AccountPurgeService`) |

**30일은 `packages/core` 의 `ACCOUNT_RETENTION_DAYS` 하나에서 나온다.**
API·웹·앱·약관·방침이 전부 이 값을 읽는다. 기간을 바꾸려면 여기만 고친다 —
손으로 적힌 곳이 없어야 고지와 실제가 어긋나지 않는다.

## 고칠 때 지킬 것

1. **코드를 고치면 방침도 고친다.** 방침은 약속이 아니라 사실 고지다.
   수집 항목이 늘거나 위탁처가 바뀌면 `privacy.ts` 를 함께 고친다.
2. **면책 조항을 넓히지 않는다.** 약관규제법 제7조는 사업자의 고의·중과실 책임을
   통째로 면제하는 조항을 무효로 본다. "어떤 경우에도 책임지지 않는다"고 적으면
   그 조항만 무효가 되어 오히려 보호가 사라진다. 지금 문서는 통제할 수 없는 사유를
   구체적으로 열거하고 배상 범위를 민법 제393조(통상손해)에 맞춰 두었다.
3. **개정하면 `effectiveFrom` 을 올리고 공지한다.** 이용자에게 불리한 변경은
   시행일 30일 전부터 공지한다고 약관에 적어두었다.

## 아직 남은 것

- 이 문서들은 **법률 검토를 받지 않았다.** 실제 서비스를 열기 전에 한 번 보이는 편이 좋다.
- 소셜 연결 해제(카카오 `unlink`, 구글 토큰 취소)는 하지 않는다. 서버가 소셜
  액세스 토큰을 보관하지 않아 사후에 해제할 수단이 없다. 스토어 정책이 요구하는 것은
  **우리 쪽 계정과 데이터의 삭제**라 이것만으로 충족되지만, 이용자의 카카오·구글
  «연결된 앱» 목록에는 남는다. 필요해지면 카카오 어드민 키로 붙일 수 있다.
