## 2. 서비스 배경

기존 습관 관리 서비스는 대부분 다음 요소로 구성된다.

- 체크리스트
- 연속 달성일(Streak)
- 달성률
- 캘린더
- 알림

이 방식은 습관 관리에는 효과적이지만 지속적인 참여 동기를 제공하기에는 부족하다.
특히 **연속 기록 중심 구조는 하루의 실패로 긴 기록이 끊어지면서 의욕을 떨어뜨린다.**

「나 VS 나」는 이를 단순한 체크리스트가 아니라 **매일 나 자신과 벌이는 경기**로 재해석한다.

- 오늘 해야 할 일을 수행하면 → 승리
- 수행하지 못하면 → 패배
- 실패도 삭제 대상이 아니라 **전적으로 남는 기록**

사용자의 목표는 완벽한 연속 기록이 아니라 **장기적으로 자신의 승률을 높이는 것**이다.

---

## 3. 핵심 철학

> 경쟁 상대는 다른 사람이 아니라 나 자신이다.

- 오늘의 나 vs 어제의 나
- 하고 싶은 나 vs 하기 싫은 나

다른 사용자의 기록과 랭킹은 **비교를 통한 좌절**이 아니라 **성장 자극과 동기부여를 위한 보조 기능**으로만 사용한다.

---

## 4. 핵심 목표

1. 사용자가 매일 해야 할 일을 명확히 확인하고 수행 결과를 기록하게 한다.
2. 기록을 장기간 축적해 성장 과정을 시각적으로 확인하게 한다.
3. 게임의 승패·전적 개념을 자기계발에 적용해 지속 참여 동기를 제공한다.

## 5. 핵심 개념

### 5.1 미션

사용자가 반복적으로 수행할 자기계발 활동.

예시
- 영어 공부 30분
- 헬스 1시간 30분
- 알고리즘 2문제
- 독서 30분
- 프로그래밍 공부 1시간

미션 설정 항목
- 미션명
- 카테고리
- 수행 요일
- 목표량
- 단위
- 난이도
- 공개 여부
- 활성화 여부

## 6. 승패 시스템

### 6.1 미션 승패

각 미션은 하나의 경기로 취급한다.

| 결과 | 기록 |
| --- | --- |
| 완료 | 1승 |
| 미완료 | 1패 |

예시 (하루)

| 미션 | 결과 |
| --- | --- |
| 영어 공부 | 승 |
| 헬스 | 승 |
| 알고리즘 | 패 |
| 독서 | 승 |
| 프로그래밍 공부 | 승 |

```
오늘 미션 전적
5전 4승 1패
```

### 6.2 달성률

```
달성률 = 완료한 미션 수 ÷ 그날 확정된 전체 미션 수
```

**분모는 그날의 전체 미션 수다.** 아직 진행 전인 미션도 분모에 들어간다.
→ 하루가 진행되면서 달성률이 0%부터 차오른다.

**부분 달성은 없다.** 목표량을 얼마나 채웠든 완료 아니면 미완료다.
목표량(30분, 2문제)은 사용자에게 보여주는 기준일 뿐 판정에 쓰지 않는다.

> 30분 중 20분을 한 것이 승인지 패인지 매번 판단하게 만들면 승부라는 개념이 흐려진다.

**난이도는 달성률에 반영하지 않는다.** 난이도는 랭킹 활동 점수(18장)에만 쓴다.

### 6.3 일일 승패

개별 미션 전적과 **별도로** 하루 전체의 승패를 기록한다.

```
미션 전적    5전 3승 2패
달성률       60%
오늘의 승부  WIN
```

| 달성률 | 결과 |
| --- | --- |
| 50% 초과 | **승 (WIN)** |
| 정확히 50% | **무 (DRAW)** |
| 50% 미만 | **패 (LOSE)** |

**이 기준은 운영자가 고정한다. 사용자가 바꿀 수 없다.**
모든 사용자가 같은 기준이어야 승률과 랭킹이 비교 가능해진다.

> **무승부는 미션 개수가 짝수인 날에만 나온다.**
> 홀수 개인 날은 정확히 50%가 수학적으로 나오지 않는다. (5개 → 40% 또는 60%)

### 6.4 하루의 경계

**사용자 타임존 기준 자정**에 하루가 끝난다. 자정까지 완료되지 않은 미션은 패로 확정된다.

### 6.5 그날의 미션은 하루 시작에 확정된다

하루가 시작되면 그날 수행할 미션이 `DailyMission`으로 확정된다(34장).
**확정된 뒤에는 그날의 미션을 삭제하거나 비활성화해도 오늘 승부에서 빠지지 않는다.** 변경은 다음 날부터 반영된다.

미션 **추가는 당일에도 허용한다.** 추가는 분모를 늘려 자신에게 불리하므로 악용될 수 없다.

> **이 규칙이 없으면 승부를 피할 수 있다.**
> 23:00에 3개 중 1개만 완료해 패배가 예정된 상태에서, 못 한 2개를 삭제하면 100% 승리가 되고 전부 삭제하면 쉬는 날이 된다.
> 판을 바꿔서 결과를 피하는 것을 막아야 한다. (37장 원칙)

### 6.6 쉬는 날

그날 확정된 미션이 **0개이면 승부가 열리지 않는다.**

| 항목 | 처리 |
| --- | --- |
| 전적 | **포함하지 않는다** (분모에서 제외) |
| 연승 | **끊기지 않는다** (유지, 증가도 없음) |
| 잔디 | 무색 (기록 없음) |

> 쉰 날을 전적에 넣으면 승률이 의미를 잃는다.
> 연승이 끊기면 주말에 쉬는 사용자는 연승을 쌓을 수 없다.

### 6.7 지난 기록 수정

**7일 이내의 기록은 수정할 수 있다. 그 이후는 불가능하다.**

체크를 깜빡하는 일은 실제로 흔하므로 소급 수정을 허용한다.
다만 무기한 허용하면 기록의 의미가 사라지므로 7일로 제한한다.

**이 규칙이 만드는 설계 제약** (기술 문서에서 다시 다룬다)

- 과거 기록이 바뀌면 **연승·승률·시즌이 소급해서 바뀐다**
- 따라서 **연승·승률·시즌 집계는 저장하지 않고 계산한다**
- 7일이 지난 기록은 불변이므로, 나중에 성능이 필요해지면 **그 경계부터 캐싱**할 수 있다
- 시즌 결과는 **월말 + 7일**이 지나야 확정된다

## 7. 전적

두 가지 전적이 존재한다.

### 미션 전적
개별 목표 수행 결과의 누적 기록. 미션은 완료/미완료뿐이라 무승부가 없다.

```
583전 421승 162패
승률 72.2%
```

### 일일 전적
하루 전체 승패의 누적 기록. **무승부가 있다.**

```
127전 94승 5무 28패
승률 74.0%
```

**승률 = 승 ÷ 전체.** 무승부는 분모에 포함하고 분자에서 뺀다. (94 ÷ 127 = 74.0%)
쉬는 날은 전체에 포함하지 않는다.

연속 기록이 끊기는 방식이 아니라 **장기간의 성장**을 확인할 수 있다.

## 8. 잔디 시스템

GitHub Contribution Graph와 유사한 형태로 활동 기록을 시각화한다.
각 칸은 하루를 의미하고, **농도는 그날의 목표 달성률**을 나타낸다.

| 상태 | 달성률 | 표현 |
| --- | --- | --- |
| 쉬는 날 | 미션 0개 | 투명 / 배경색 |
| 패 | 0~49% | **무채색(회색)** 1단계 |
| 무 | 50% | **별도 색상** 1단계 |
| 승 | 51~74% | 주 색상 ● |
| 승 | 75~99% | 주 색상 ●● |
| 완승 | 100% | 주 색상 ●●● |

**승리만 농도를 셋으로 나눈다.** 51%로 겨우 이긴 날과 전부 해낸 날이 구분된다.
패와 무는 각각 한 단계씩만 쓴다.

### 8.1 색 제약 조건

구체적인 색은 화면설계에서 정하되, 아래 네 가지는 지킨다.

**1. 배경 대비 강도를 지킨다 — 승 > 무 > 패**
흑백으로 봐도 읽혀야 한다. 무승부가 패배보다 또렷해야 "절반은 했다"가 보인다.

> 밝기가 아니라 **배경과의 대비**가 기준이다. 흰 바탕에서는 진할수록 강하고, 어두운 바탕에서는 밝을수록 강하다.

**2. 승과 무는 색상(hue)이 충분히 달라야 한다**
같은 색의 농도로 구분하면 눈이 못 따라간다. 색상을 바꾼다.

> **초록(승) + 노랑·주황(무) 조합은 적록색약에게 거의 같아 보인다.**
> 안전한 조합은 **초록(승) + 파랑 계열(무)**이다. 어떤 색약 유형에서도 갈린다.

**3. 패배는 무채색으로 간다. 빨강을 쓰지 않는다.**
매일 보는 화면에 빨간 칸이 박히면 "고쳐야 할 오류"로 읽힌다. 2장에서 비판한 "연속 기록이 끊겨 의욕이 꺾이는" 구조를 색으로 재현하게 된다.
회색이면 처벌하지 않으면서 기록은 남는다. **"실패도 기록이다"와 "실패를 낙인찍지 않는다"가 둘 다 성립한다.**

**4. 색 축을 토큰으로 뺀다**
색약 모드는 MVP에 넣지 않아도 되지만, 색을 토큰으로 관리하면 나중에 스위치 하나로 바꿀 수 있다. 하드코딩하면 전 화면을 찾아다녀야 한다.

### 8.1.1 확정 팔레트

https://coolors.co/eec643-141414-eef0f2-0d21a1-011638

**단일 라이트 테마.** 다크 모드는 만들지 않는다. 사용자가 테마를 고르는 것은 평생 한 번인데, 개발자는 색을 추가할 때마다 두 벌을 확인해야 한다.

| 역할 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 메인 | `#141414` 오닉스 | 주 텍스트, 주요 버튼, 활성 내비 |
| 메인 | `#EEC643` 토스카나의 태양 | **무승부 전용** |
| 서브 | `#FAFAFA` | 페이지 배경 |
| 서브 | `#0D21A1` | 링크·강조 |
| 서브 | `#011638` | 진한 강조 |
| 표면 | `#FFFFFF` | 카드 |

**승부 색**

| 상태 | 값 |
| --- | --- |
| 승 51~74% | `#A9E3BE` |
| 승 75~99% | `#47B877` |
| 완승 100% | `#14804A` |
| 무 | `#EEC643` |
| 패 | `#D7263D` |
| 쉬는 날 | 채우지 않고 테두리만 |

**팔레트 밖에서 가져오는 색은 둘뿐이다** — 승리 초록(잔디 관습)과 패배 빨강.

**골드는 무승부 전용이다.** 연승 숫자와 완승 배지는 승리 초록을 쓴다.
같은 색이 여러 의미를 가지면 화면에서 무엇을 뜻하는지 매번 해석해야 한다.

**쉬는 날은 채우지 않는다.** 채움 여부로 구분하면 명도를 억지로 벌릴 필요가 없다.

### 8.1.2 알고 있어야 할 두 가지

**대비 위계가 8.1의 규칙(승 > 무 > 패)과 어긋난다.**
빨강 패배가 가장 또렷하고 옅은 골드 무승부가 가장 약하다. 잔디에서 패배가 제일 눈에 띈다는 뜻이다.
2장에서 비판한 "실패로 의욕이 꺾이는 구조"를 색으로 재현할 위험이 있다.
승부 서비스라 승패가 또렷한 편이 낫다는 판단으로 이 조합을 택했다.

**적록색약에서 승리 초록과 무승부 골드가 가까워진다.**
명도 차이(골드가 훨씬 밝다)로 구분되지만 색상만으로는 갈리지 않는다.
잔디 범례를 반드시 두고, 날짜를 눌렀을 때 상세에서 `WIN / DRAW / LOSE` 를 글자로 확인할 수 있어야 한다.

### 8.2 무승부를 잔디에서 구분하는 이유

무승부는 **미션 개수가 짝수인 날에만** 나오는 희귀 상태다.
그래도 색을 따로 주는 이유는, 전적에 `5무`로 남는 상태를 잔디에서 못 찾으면 사용자가 그 날을 확인할 방법이 없기 때문이다.

잔디를 선택하면 해당 날짜의 상세 기록을 확인할 수 있다.

```
2026년 8월 26일

5전 4승 1패
달성률 80%

영어 공부       ✓
헬스            ✓
알고리즘        ✕
독서            ✓
프로그래밍 공부  ✓

오늘의 승부: WIN
```

## 9. 연승

**일일 승리를 연속으로 달성**하면 연승으로 기록한다.

```
🔥 현재 7연승
```

| 그날 결과 | 연승 |
| --- | --- |
| 승 | +1 |
| 무 | **끊김** |
| 패 | **끊김** |
| 쉬는 날 | 유지 (증가 없음) |

통계 항목
- 현재 연승
- 최장 연승
- 이번 달 연승
- 역대 최장 연승

연승이 끊어지더라도 **기존 승리 기록과 전적은 유지된다.**
서비스는 연승보다 **전체 전적과 승률을 더 중요한 지표**로 취급한다.

## 11. 회고

하루에 **한 줄 회고**를 남길 수 있다.

```
알고리즘은 못 했지만 운동과 영어 공부는 계획대로 끝냈다.
```

월말에는 해당 기록을 기반으로 월간 회고를 확인한다.

```
8월 시즌 종료

31전 24승 7패
승률 77.4%
```

## 35. 서비스 차별점

1. **체크가 아닌 승부** — 해야 할 일을 체크하는 게 아니라 매일 자신과 한 경기를 치른다.
2. **실패도 기록이다** — `29승 1패`. 하루의 실패가 이전 29번의 승리를 무효화하지 않는다.
3. **성장의 시각화** — 잔디, 승률, 시즌, 연승으로 장기 변화를 확인한다.
4. **비교보다 자기 경쟁** — 타인과의 경쟁은 부가 요소, 핵심 경쟁 상대는 과거의 자신이다.
5. **자기계발의 게임화** — 전적, 승률, 연승, 시즌, 업적, 챌린지로 자기계발을 장기 게임처럼 만든다.

## 37. 서비스가 지켜야 할 원칙

- **완벽함보다 꾸준함** — 하루의 패배가 전체 기록을 망치지 않는다.
- **기록은 솔직하게** — 실패도 성장 과정의 일부로 남긴다.
- **비교보다 성장** — 타인의 기록은 동기부여 수단이지 최종 목표가 아니다.
- **사용자가 시스템을 위해 살지 않도록 한다** — 목표 개수를 늘리고 쉬운 미션을 반복해 점수를 올리는 행동보다 실제 삶의 변화를 중요하게 평가한다.

## 38. 최종 서비스 비전

「나 VS 나」는 단순한 체크리스트 앱이 아니다.

사용자가 매일 자신에게 작은 도전을 만들고, 그 결과를 승리와 패배로 기록하면서, 장기간 자신의 변화를 확인하는 서비스다.

오늘 하루 패배할 수도 있다. 하지만 기록은 끝나지 않는다.
어제 졌다면 오늘 다시 붙으면 된다.

그리고 수개월, 수년 뒤 사용자의 잔디와 전적 자체가
**그 사람이 어떻게 살아왔는지를 보여주는 하나의 기록**이 되는 것을 목표로 한다.
